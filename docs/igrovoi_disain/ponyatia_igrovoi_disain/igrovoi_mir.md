# {{page.title}}

## Что?: 
Искусственная среда, в которой происходят события игры.

## Как?:
Состоит из:
 - Локаций  
 - Лора  
 - Правил  
 - Персонажей  

## Какой?:
- Линейный - локации идут по порядку. Лор строго выстроен. Нету, или почти нету возможности свободного исследования.
- Открытый - мир состоит из уже подготовленных локаций. Лор разбит на части и распределен по локациям. Есть возможность свободного исследования. Мир не изменяется по мере исследования.
- Динамический - мир состоит из первоначального набора локаций. Лор разбит на части и распределен по локациям. Есть возможность свободного исследования. Мир изменяется по мере исследования, возникают или исчезают локации, изменяются персонажи.
