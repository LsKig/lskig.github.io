# {{page.title}}

## Что?: 
Виртуальное пространство, которое задает контекст для взаимодействия игрока с игровыми механиками и формирует список его возможных операторов(Глаголов).

## Какая?:

По пространственной структуре:
- Линейные
- Открытые
- Ветвящиеся
- Абстрактные

По функциональному назначению:
- Конфликтная
- Хаб
- Транзитная
- Наративная

По уровню стабильности
- Статическая
- Временная
