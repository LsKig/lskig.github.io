Раздел Генераторы(https://lskig.github.io/docs/generators.html):
Здесь реализую(не без помощи нейронок) разные помошники по НРИ и не только.
Уже есть:
- Модуль помощи в Алхимии по Ведьмак НРИ
- Модуль помощи по крафту для Ведьмак НРИ
- Калькулятор расчета попадания и урона для Ведьмак НРИ
- Генератор детективного сюжета по системе Dirty World
- Несколько генераторов имен и генератор квестов для Blades in the dark

Раздел Игровой дизайн(https://lskig.github.io/docs/igrovoi_disain.html):
Потихонечку собираю тут понятия по игровому дизайну и пишу статьи о применении мягкого игрового дизайна в НРИ.

Раздел Интересное(https://lskig.github.io/docs/interesting.html):
Собираю разные полезные штуки. То что мне когда-то пригодилось или просто было интересно поизучать. 

Раздел Настольные ролевые игры(https://lskig.github.io/docs/nri.html):
Здесь хранится информация по уже сыграным мной играм и некоторая информация по системам. Также тут лежат некоторые хаки на правила систем.

Раздел Сценаристика(https://lskig.github.io/docs/scenaristika.html):
База терминов по сценаристике, а также несколько статей с наблюдениями и мои собственные попытки написать что-то вразумительное относительно сценариев.
